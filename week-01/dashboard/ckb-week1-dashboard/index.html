Cell Model & Lock Script

Cell Model

Mỗi Cell có capacity, lock, type (tùy chọn) và data. Giao dịch tiêu thụ các input Cell và tạo các output Cell mới.

Lock Script

Lock Script xác định điều kiện sử dụng Cell. Các trường code_hash, hash_type và args được hiển thị bên trong từng output Cell phía trên.
